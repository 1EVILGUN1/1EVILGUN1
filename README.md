# 🌟 Избранные проекты

Вот несколько проектов, демонстрирующих мою экспертизу:

1. **Explore With Me Next Version**  
   - **Описание**: Современное микросервисное приложение для управления событиями, подписками и рекомендациями. Реализована гибкая архитектура с обработкой данных в реальном времени.  
   - **Технологии**: Java 17, Spring Boot, Spring Cloud, PostgreSQL, Apache Kafka, gRPC, Docker.  
   - **Репозиторий**: [GitHub](https://github.com/1EVILGUN1/java-ewm-next-version)  

2. **Smart Home Technologies**  
   - **Описание**: Масштабируемая платформа для управления умным домом и продажи устройств. Использует Kafka и gRPC для высокопроизводительной коммуникации между сервисами.  
   - **Технологии**: Java 21, Spring Cloud, PostgreSQL, Apache Kafka, gRPC, Docker.  
   - **Репозиторий**: [GitHub](https://github.com/1EVILGUN1/smart-home-tech)  

3. **ShareIt**  
   - **Описание**: Сервис шеринга вещей с системой бронирования и управления запросами. Обеспечивает надежность и защиту от конфликтов бронирования.  
   - **Технологии**: Java 21, Spring Boot, PostgreSQL, Docker.  
   - **Репозиторий**: [GitHub](https://github.com/1EVILGUN1/java-shareit)
